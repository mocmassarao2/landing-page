# 🎬 Landing Page - Filmes & Séries

Uma landing page moderna e responsiva desenvolvida em **React** e **Vite**, projetada para apresentar destaques de filmes e séries populares.

---

## 🚀 Tecnologias Utilizadas

- **React**
- **Vite**
- **CSS3**
- **JavaScript (ES6+)**

---

## 💻 Como Rodar o Projeto Localmente

### Pré-requisitos
Certifique-se de ter o **Node.js** e o **npm** instalados em sua máquina.
